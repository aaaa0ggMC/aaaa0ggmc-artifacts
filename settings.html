Encrypted blocks on artifact pages are rendered in the browser with a single artifact key. The key never leaves this device and is not stored on any server.

Status: no key set

Stored only in this origin's localStorage as artifact_key. It is never sent to the server.

How it works ​

  • The build encrypts each ::: secret ... ::: block with AES-256-GCM (PBKDF2-SHA256 derived key).
  • This page stores the key in localStorage under artifact_key.
  • Artifact pages read that key, decrypt the block, validate the render spec, and let Vue render it.
  • Clear the key at any time with Forget; encrypted blocks immediately fall back to the locked placeholder.
